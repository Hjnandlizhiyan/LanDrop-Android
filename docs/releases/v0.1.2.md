# LanDrop Android v0.1.2

- Share files and text between Android phones and Windows PCs on the same LAN.
- Chinese/English UI, system sharing, selectable receive folders, and background receiving.
- Creator links and QQ community **305402575** in Preferences.
- Stable device selection without repeated flickering.

**Android 8.0+ · Signed APK · Version 0.1.2**

If you previously installed a debug build, its signature differs. Save important received files outside the app folder and note device settings before uninstalling it, then install this release. Future releases with the same signing key can update in place.

安卓 8.0 及以上。此前 debug 测试包因签名不同不能直接覆盖；先另存重要接收文件、记录配置，再卸载测试包并安装此正式包。

Use a trusted local network. Add each other's IP address and port on both devices. See the README for setup and storage details.
